# エンゼルガーデン幼稚園 先生募集リール（イラスト版・試作）

![poster](poster.jpg)

Instagramリール用の縦長動画です。1080×1920、30秒、30fps、音付き。完成品は `reel.mp4`。

## 流れ

| 秒 | 場面 | 画面の文字 |
|---|---|---|
| 0–3.5 | ボールが跳ねて太陽になる。丘の向こうから子どもが顔を出す | エンゼルガーデン幼稚園で／いっしょに働く／先生を／さがしています。 |
| 3.5–7.5 | 園舎の前で先生が子どもを出むかえる | 朝は「おはよう！」から。 |
| 7.5–11.5 | ブランコ、ボール遊び、ジャンプ | 園庭で、思いっきり。 |
| 11.5–15.5 | クレヨンで太陽と花を描く | つくって、描いて。 |
| 15.5–19.5 | お弁当のふたが開いて「いただきます！」 | お昼は、みんなで。 |
| 19.5–23.5 | 夕方、手をふって帰る子どもたち | 「また明日ね」と手をふって。 |
| 23.5–27 | 描いた絵を掲げてジャンプ、先生が拍手 | 子どもの「できた！」を／いちばん近くで／見られる仕事です。 |
| 27–30 | 天使の羽のマーク、先生と子どもが手をふる | エンゼルガーデン幼稚園／先生募集中！／くわしくはプロフィールのリンクから |

文字はすべて `reel.html` の中にあり、書きかえて書き出し直せます。天使の羽と輪のマークは試作用に描いたもので、園のロゴではありません。

## 書き出し直す

```sh
pip install numpy scipy imageio-ffmpeg
python3 audio.py        # reel-audio.wav
FFMPEG=$(python3 -c "import imageio_ffmpeg as i; print(i.get_ffmpeg_exe())") node render.mjs   # reel.mp4（約2分）
```

`reel.html` をブラウザで開いてタップすると、その場で再生されます。`?t=12.5` を付けると、その時刻の1枚を表示します。

フォントは Zen Maru Gothic（SIL Open Font License）を `fonts/` に入れています。
